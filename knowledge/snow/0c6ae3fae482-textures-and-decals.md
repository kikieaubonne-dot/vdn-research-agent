## Étapes reproductibles

Instructions extraites automatiquement : procedure partielle, ordre et fonctionnement non verifies.

1. - Change the texture or decal `Class.Decal.Color3|Color3` property to set a color tint using RGB color codes. -- [Documentation Roblox](https://create.roblox.com/docs/en-us/parts/textures-decals.md)
2. - Change the texture or decal `Class.Decal.Transparency|Transparency` property to a value between the default of **0** (fully visible) and **1** (invisible). -- [Documentation Roblox](https://create.roblox.com/docs/en-us/parts/textures-decals.md)
3. - For a texture, set its [scale](#scale-textures) and [offset](#offset-textures). -- [Documentation Roblox](https://create.roblox.com/docs/en-us/parts/textures-decals.md)
4. To create a texture or decal, you must add either a `Class.Texture` or `Class.Decal` object to a part or union. -- [Documentation Roblox](https://create.roblox.com/docs/en-us/parts/textures-decals.md)
5. You can [import](/docs/en-us/projects/assets/manager.md#asset-import) images for textures and decals to Studio for use between games, and [distribute](/docs/en-us/production/creator-store.md) them to the [Creator Store](/docs/en-us/production/creator-store.md). -- [Documentation Roblox](https://create.roblox.com/docs/en-us/parts/textures-decals.md)
6. > **Info:** Every texture or decal image that you create and import to Roblox must adhere to the [Community Rules](https://en.help.roblox.com/hc/articles/203313410) and [Terms of Use](https://en.help.roblox.com/hc/articles/115004647846). -- [Documentation Roblox](https://create.roblox.com/docs/en-us/parts/textures-decals.md)

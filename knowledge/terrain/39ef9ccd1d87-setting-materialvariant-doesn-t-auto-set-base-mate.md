Despite it being a really small issue it’s beyond frustrating - especially if you want to change the material variant of a bunch of parts and forget about it, then see this once you deselect them all. -- [Roblox DevForum](https://devforum.roblox.com/t/setting-materialvariant-doesnt-auto-set-base-material/2692682)
2. I was confused when I tried to set a part to a material variant then after some trial and error I figured out I had to set the matching base material first(manually). -- [Roblox DevForum](https://devforum.roblox.com/t/setting-materialvariant-doesnt-auto-set-base-material/2692682)
3. When you change the material variant on a part using the dropdown in the properties window, the material associated with that variant is no longer automatically selected. -- [Roblox DevForum](https://devforum.roblox.com/t/setting-materialvariant-doesnt-auto-set-base-material/2692682)
4. This means you have to manually remember the material and set it additionally yourself. -- [Roblox DevForum](https://devforum.roblox.com/t/setting-materialvariant-doesnt-auto-set-base-material/2692682)
5. Previously the material was set automatically when choosing a variant. -- [Roblox DevForum](https://devforum.roblox.com/t/setting-materialvariant-doesnt-auto-set-base-material/2692682)
